MY CLOSET – brezplačna prva različica

Vsebuje: index.html, manifest.webmanifest, sw.js, icon.png, icon-512.png.

OBJAVA BREZ PLAČILA:
1. Ustvari brezplačen račun na GitHubu.
2. Ustvari javni repozitorij, npr. my-closet.
3. Naloži vse datoteke iz te mape v koren repozitorija.
4. Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save.
5. Ko je objava pripravljena, odpri HTTPS naslov GitHub Pages v Safariju na iPhonu.
6. Safari > Deljenje > Dodaj na začetni zaslon.

POMEMBNO:
- Na GitHub naloži samo aplikacijske datoteke, nikoli svojih zasebnih fotografij garderobe.
- Fotografije se shranjujejo lokalno v IndexedDB na tvoji napravi.
- Redno izvozi varnostno kopijo v Nastavitvah. Kopija vsebuje tudi fotografije.
- Brezplačni GitHub Pages je namenjen statičnemu gostovanju; v tem projektu ni strežniške AI.
- Predlogi outfitov so trenutno pravila + naključni izbor, ne generativna AI.
- Za delovanje brez povezave najprej enkrat odpri objavljeno aplikacijo z internetno povezavo.
